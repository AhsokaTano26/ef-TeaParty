# 现场准备与恢复说明

建议先保存题库和素材，完成素材检查，再用实际投影电脑试播，最后下载活动 ZIP。后台编辑预览、素材检查和独立投影各有作用；检查通过后，仍需确认现场声音、全屏和播放片段。

## 查看投影反馈

打开独立投影页 `/stage`，在投影端点击「启用投影声音」；需要隐藏浏览器工具栏时，再点击「全屏显示」。主持端的「投影视频全屏」控制视频铺满活动画面，与浏览器全屏分别控制。

「现场控制 → 投影端状态」约每 2 秒显示各投影窗口的最近回报时间、页面与版本、全屏、声音、媒体状态、实际进度和同步偏差。后台预览不计入投影窗口。

- 「已启用 · 待播放确认」表示已打开声音开关；播放素材后再确认是否显示有声播放，并实际听音。
- 「浏览器阻止播放」需要在投影端点击继续播放。远程指令不能替代浏览器要求的本机点击。
- 「等待同步」「连接延迟」「已离线」时，当前媒体进度不再作为有效回报显示；先检查对应窗口和连接。

## 素材检查与下一页准备

在「活动设置 → 活动素材检查」点击「开始检查」。默认检查已启用页面中的图片、音视频、立绘、背景及答案素材；需要核对备用题目时勾选「包含未启用页面」。可停止检查，也可选择「只看异常和待确认」。修改题库后重新检查。

检查发生在主持浏览器中，主要确认文件可访问、图片可读取及音视频信息或首帧可读取。外链依赖网络，部分音视频会标为需试播。**预检不能代替投影电脑上的实际播放与听音，也不保证整个视频都能解码。**

独立投影自动尝试准备下一个已启用页面的可见素材：最多四张图片和一个音视频候选，排除答案素材、隐藏媒体和未启用页面。只准备同源资源；图片需不超过 4 MB，音视频只读取开头最多 1 MB。任务有超时，换页或关闭投影会取消旧任务。该过程不会把整段大视频提前下载，也不表示素材已经完整缓存；外链或超限素材在实际显示时正常加载。

## 大文件上传

题库媒体、开场立绘和背景上传共用素材上传面板，可查看百分比、已传大小、速度及预计剩余时间。视频上限为 3 GB（3 × 1024³ 字节），图片与音频上限为 256 MB。

1. 选择文件后保留当前编辑页面，等待上传及「校验并保存」完成。
2. 需要停止时点击该文件的取消按钮；离开对应编辑页面也会取消待完成任务。
3. 失败后可点击「重新上传」。**重试从头传输，不支持断点续传**；成功后同一任务只添加一次素材。
4. 上传完成后保存页面或活动设置，再检查投影效果。

## 欢迎页显示

在题库管理选中欢迎页，可分别开关「显示团队比分」和「显示倒计时」，保存页面后同步到投影。比分显示还受活动全局比分开关控制；关闭倒计时显示不会停止计时。这两个设置只影响欢迎页。

欢迎页标题采用活动标题，随中英文长度调整字号。修改标题后查看编辑预览，确认换行与立绘遮挡；其他页面标题沿用各自布局。

## 立绘排版

在题库管理的「开场立绘」中选择角色，并在上方预览拖动位置或右下角缩放。

- 「辅助线与 5% 安全区」只在编辑预览显示；「自动吸附」帮助对齐画面和其他立绘。按住 Alt / Option 暂停吸附，方向键可精调，Shift 加速。
- 「锁定布局」固定位置、大小、翻转和层次；锁定后仍可改名或移除。
- 撤销/重做作用于本页立绘，一次拖动或连续缩放作为一步历史。可使用按钮，或在立绘编辑范围内使用 Ctrl / ⌘ Z、Ctrl / ⌘ Shift Z。
- 欢迎页的「恢复推荐排版」恢复现有七位角色的推荐位置、大小、层次和翻转状态，保留自定义图片地址、额外立绘与锁定项；这一步也可撤销。

辅助线、吸附和撤销不会自动发布草稿。完成排版后点击保存页面。

## 备份与恢复

在「活动设置 → 活动备份与恢复」点击「下载完整活动备份」。ZIP 保存题库、答案、计分、抽签记录、当前页面及播放/计时进度，并打包活动当前引用且可读取的本地素材，包括禁用页面素材、答案媒体、立绘和背景。未引用的上传文件不打包；程序本身需在目标电脑另行部署。

外链只记录地址，文件不会下载进 ZIP；本地缺失或不可读取的素材会列为待处理项。归档最大 32 GB，单个素材最大 3 GB。需要离线使用时，先把外链素材下载并上传到活动中，保存后重新备份。

1. 恢复前先下载当前活动 ZIP，作为方便回退的副本。
2. 选择要恢复的 ZIP，等待上传和校验；核对活动名称、页面、组别、记录数量及素材清单。外链和缺失提示需要逐项确认。
3. 点击「确认恢复…」，在弹窗中确认替换。预检后若活动又有操作，或预检超过 15 分钟，应重新预检。
4. 恢复后媒体与倒计时保持暂停；核对当前页面、积分及素材，再由主持人重新开始。可再运行一次素材检查并试播。

每次恢复前，系统会先把当前状态写入默认数据目录下的 `data/pre-restore-*.json`。旧素材和历次恢复目录保留，不自动清理，供回退使用；自动 JSON 快照只含状态，必须配合原素材。最直接的回退方式是通过上述入口恢复先前下载的 ZIP。

题库 JSON 只包含配置，成绩 CSV 只用于成绩归档。仅复制 `data/` 也不一定覆盖活动引用的 `assets/` 素材；迁移活动优先使用 ZIP，并核对归档中的外链和缺失清单。
