# 冬日茶话会

为重庆大学动漫社偶研部的线下活动提供 Go + React 主持后台及独立投影页。本机优先，能够通过局域网连接大屏，所有持久化数据留在 `data/state.json`，无需外部数据库。

## 活动流程

页面按用户定义的顺序连续播放，支持暖场、开场/规则、单选、海龟汤、猜歌、你画我猜、比分/颁奖。新安装使用空白流程模板；若存在本地 `assets/seed.json`，使用该初始题库。活动题库和素材不纳入系统仓库，背景由主持人在后台设置。未知答案的题目应保持禁用，启用单选题时会校验选项和答案。

主持端 `/` 负责切页、显隐答案、计时、选组判分和播放。投影端 `/stage` 通过 SSE 同步，会先请求一次用户点击来启用音频。音视频使用真实 HTMLMediaElement，支持暂停、重播、跳转及开始/结束秒数。暂停位置及播放时间跨屏同步，切页停止旧媒体。题目与媒体标题在揭晓前不能暴露答案。

计分采用可撤销记录：每题每组最多一条判分记录，重新判定替换该记录；手动调整单独记账，可选择个人昵称并记个人积分。组别和每题加扣分可编辑。切页不清空成绩，重启恢复现场。

抽签支持昵称池、整数范围、数量及不重复；Go 使用 crypto/rand 抽取，抽签结果与历史持久化并同步投影。重置抽签池只清空相应历史。空池、范围反转、耗尽均返回具体错误。

## 接口与安全

Go 标准库 HTTP 服务，提供公开状态和公开 SSE，后台请求使用 HttpOnly SameSite cookie，密码来自环境变量或首次启动随机生成。公开 DTO 不包含未揭晓的答案、解析、答案素材及整套题库。JSON 配置导入严格校验，写盘先临时文件再原子替换；失败不更新内存。限制上传大小和媒体类型，上传资源使用随机名称；视频支持 Range。

## 验证

Go 行为测试覆盖计分替换/撤销、持久化、公开答案隔离、抽签不重复与范围、配置校验和 HTTP 登录。前端通过 TypeScript 构建检查；按用户要求，在可见 Microsoft Edge 中使用苹果辅助功能验证新建题目、排序、投影同步、真实媒体、判分及抽签。检查桌面与窄屏截图，不使用无头浏览器。
