# 视频进度与倍速验收

日期：2026-10-13。

## 功能

后台每个视频的播放工具栏新增完整进度条、当前／总时长、前后 10 秒跳转以及七档 0.5–2 倍速。进度条支持指针拖动及键盘方向键、Home、End，松开提交，Escape 取消。控件使用现有浅色／深色主题。音频控制和暖场平铺分区保留。

进度条基于现有预览媒体的时长回报，不重复加载视频。拖动限制在配置片段与真实文件范围内。倍速经服务器统一保存并广播，服务器和投影均按倍速推进共享时间；暂停、重播、延迟起播、抽签暂停、存档恢复均使用同一规则。

## 验证证据

- `npm test`：69 项通过，覆盖倍速推进、延迟／暂停／晚加入、漂移修正、真实视频时长及跳转边界。
- `go test -race ./...`：全部通过，覆盖倍速命令、旧速率进度锚定、待播放时间、过期命令、范围校验、切页复位和存档兼容。
- `npm run build`：TypeScript 与 Vite 构建通过。
- React 服务端渲染检查：片段范围、当前／总时间、七档倍速选中状态、暖场分区、音频控制分支均通过。
- 隔离的 8085 HTTP 服务实测：登录 → 定位 20 秒 → 2× → 播放 → 暂停，位置符合实际服务器时间乘以 2；前后跳转、0.75× 公共状态及非法倍速拒绝通过。测试服务已关闭。
- 8080、8084 已重启并提供最新资源，积分、题库及抽签历史保留，旧会话默认 1×。主服务当前页与暂停状态保持一致；预览服务随后收到新的播放、定位及全屏操作，修订号从 215 增至 218，保留这些后续操作，没有回滚现场状态。

## 交互审查与限制

代码复核修正三项边界：旧视频秒数输入失焦与倍速提交竞争；完整视频到末尾后播放按钮需重播；配置片段尾超过真实文件长度时应按实际终点停止。速度按钮可换行，小屏前后跳转与倍速分别布局，长视频显示小时。拖动期间的暂存值不会被时钟更新覆盖，提交携带页面、素材索引及播放序号，防止过期命令作用于后续素材。

QA 评分 14/16：产品适配、层级、状态、可访问性、响应式、性能各 2；视觉和验证各 1。验证方式：代码、服务端渲染、单元／并发测试、隔离 HTTP 集成。未运行额外启发式审计脚本，此次采用针对交互及同步路径的代码复核。

苹果辅助功能返回 `Sky Computer Use native pipe startup failed`；真实浏览器视口、拖动手感及实际视频画面同步未目测验证。未使用无头浏览器。更新后后台和投影端均须刷新，旧标签页不具备倍速同步代码。
