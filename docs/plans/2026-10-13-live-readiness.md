# 冬日茶话会现场体验完善

用户已确认六项全部实施，沿用 Go + React、本地持久化与共享 Stage，保留现有活动数据。可视验收只使用可见浏览器/苹果辅助模式，不使用无头浏览器。

## 实现与分工

1. 投影反馈：独立内存心跳记录，不频繁写活动存档；后台查看当前页、声音、全屏、素材加载/缓冲/错误、播放位置和同步偏差。过期连接明确标记失联。
2. 下一页预载与素材预检：公开状态只提供下一启用页的无答案素材 URL 与类型；有上限的可取消资源读取。后台提供素材逐项检查、进度、取消与重新检查；无法验证的外链标明限制。
3. 上传：统一 XHR 进度、速度、剩余时间、取消、失败重试；保留 3GB/256MB 限制。重试从头开始并明确提示；切换页面和卸载不会将上传结果误写到另一道题。
4. 开场：每页独立比分与计时显示开关，缺省兼容现有配置；标题根据文字宽度适配，不侵入角色区。
5. 立绘：编辑专用安全区、参考线、吸附、锁定、撤销重做和推荐布局；推荐仅调整已知角色，不替换素材或移除自定义角色；一次拖动合并为一次撤销。
6. 完整活动档案：流式 ZIP 导出状态与全部引用本地素材（含答案素材）；导入先暂存校验再预览，确认后恢复。校验路径/格式/大小/哈希/引用和版本，外链单独列明；新素材采用新命名空间，失败不改当前活动，恢复前自动保存旧状态。

并行实施投影、活动档案、立绘；主任务实现上传、预检、开场渲染并负责集成。共享接口修改限制在约定区域，避免覆盖彼此与用户修改。

## 验证

- Go：活动档案往返、无权限、恶意 ZIP、版本冲突和失败回滚；心跳验证/过期；预载不泄漏答案；新增字段持久化。
- 前端：上传取消/重试/速度、预检超时/取消、吸附/锁定/历史、长标题和显示开关；保留既有媒体同步与题库预览测试。
- 集成：`go test -race ./...`、`npm test`、`npm run build`；独立临时数据目录进行 HTTP 往返和 SSR 检查。
- 最后备份两个活动状态，更新服务二进制及前端；检查 8080/8084 状态保留和新接口。真实活动不执行演示恢复，不改用户现场页与计分。

## 重点检查

上传完成前切换题目；活动档案大文件内存与磁盘使用；恢复校验后活动继续变化；预载答案泄漏；投影状态过期/新媒体切换；拖动过程中回调陈旧；旧题库缺省字段兼容。
