# 冬日茶话会 Implementation Plan

**Goal:** 交付可以运行的 Go + React 现场答题、计分、媒体及抽签系统。
**Architecture:** Go 标准库提供原子 JSON 持久化、登录和 SSE；React + Vite 提供后台和投影。
**Spec:** `docs/design.md`

## Global Constraints

- 使用用户提供的 PPT 背景和题目，不自动补写未知答案。
- 本地素材上传，离线可用；远程媒体 URL 可选。
- 主持端答案与投影公开状态严格隔离。
- 单题重复判定不得累计刷分，支持撤销。

## Review Focus

- 组别删除后仍有计分记录：要求先撤销关联记录，避免成绩失联。
- 非法导入或写盘失败：原数据保留。
- 最后一页、禁用页及删掉当前页：保持有效当前页。
- 昵称重复、数字负值、池耗尽：规范化并明确返回错误。
- 浏览器禁止自动播放：显示启用音频按钮和播放失败提示。
