# 暖场接入网易云音乐

日期：2026-10-18
状态：用户于 2026-10-19 确认继续，进入实现。

## 用户目标与已确认范围

用户希望在现有暖场环节使用网易云音乐，已确认同时需要：

- 导入公开歌曲、歌单。
- 登录自己的网易云账号，使用该账号有权播放的会员歌曲。

成功的使用流程是：主持人在暖场编辑器粘贴链接、选择歌曲、保存，在现场控制点击播放，独立投影继续显示现有唱片画面，并同步播放、暂停和进度。现有题库、上传素材、分组、积分和抽签数据继续使用。

以下为本方案的实现选择：扫码登录；接入本机运行的社区 SDK；会员歌曲以网易云实际返回的完整播放权限为准；在线歌曲需要联网。账号不保证能播放所有标注为会员或付费的歌曲。

## 当前系统约束

- Go 服务维护活动状态，通过 SSE 同步主持端和投影；前端使用原生 audio/video 与共享服务器时钟。
- 暖场媒体目前只能上传文件或填写文件直链，分享网页无法直接播放。
- `Media` 保存 `url`、名称、片段时间和唱片封面；每页媒体上限为 30。
- `data/state.json` 保存活动；`data/media` 存储公开上传文件。活动 ZIP 备份只包含活动状态和引用的本地媒体。
- 已有预加载、素材检查、草稿预览和恢复流程，接入后需要共同适配。

## 方案比较与选择

1. **嵌入网易云网页播放器**：接入工作少，但难以复用现有同步控制，也不能作为账号会员歌曲的完整方案。
2. **本机社区 SDK 适配层（采用）**：复用二维码登录、歌单详情和取流能力，Go 继续管理活动、凭据与投影播放。
3. **在 Go 内自行维护网易云协议**：减少运行时进程，但需要长期维护非公开协议和加密变化，本次不采用。

采用 `@neteasecloudmusicapienhanced/api`。已确认 npm 当前发布版本为 4.41.1，以该版本作为初始兼容性验证对象；实施时固定通过测试的版本并提交 lockfile。SDK 仅提供协议能力，产品不直接开放其完整 HTTP 服务。

## 进程与数据边界

新增 `integrations/netease/` Node 适配进程，由 Go 服务按需启动，使用标准输入输出中的 JSON 消息通信；不新增对外端口。运行依赖沿用项目要求的 Node.js 22.18+。

Go 客户端负责请求编号、并发响应分发、超时、取消、进程退出和重启。标准输出只承载协议消息；上游异常经过归一化处理，避免输出整个请求或凭据。并发数和单个响应大小设定上限，进程异常不影响原有本地音视频。

`make install` 安装前端及网易云适配依赖。`make run` 和构建后的服务在依赖存在时可以使用网易云；缺少 Node 或依赖时，后台显示可操作的安装提示，本地活动仍能运行。前端只访问现有 Go 服务。

## 后台使用流程

在题库管理的暖场页面中增加“网易云音乐”区域，沿用现有表单、提示、浅深色主题与草稿保存方式：

1. 显示连接状态：组件未安装、未登录、已登录、登录失效或暂时无法连接。
2. 未登录也可以提交公开歌曲／歌单链接；平台要求登录时明确提示。
3. 点击“扫码登录”生成二维码，显示等待扫码、等待手机确认、成功或过期；过期可刷新，关闭后停止轮询。
4. 登录后显示昵称及“退出网易云”入口，并支持读取该账号的歌单。
5. 粘贴歌曲／歌单链接或包含链接的分享文字，加载可选择的歌曲列表，显示名称、歌手、封面、时长。
6. 主持人勾选歌曲后“加入暖场列表”。按网易云歌曲编号去重，追加至现有媒体，不覆盖上传文件。导入只更新草稿，仍需点击现有“保存页面”发布。

只解析认可的网易云链接；短链接仅在限定域名和有限重定向内展开，不支持任意网站抓取。无法解析时提示粘贴网页版歌曲或歌单链接。

歌单使用分页获取。暖场媒体上限提高到 500，其余页面保持 30；列表可分批选择并明确显示剩余容量。超过上限时阻止超量添加，不能静默截断或覆盖已有媒体。

## 媒体模型与播放

`Media` 新增可选的网易云来源信息，至少包含稳定的歌曲编号；旧存档没有该字段时行为不变。导入媒体仍为 `kind: audio`，名称使用“曲名 · 歌手”，专辑封面接入现有每曲唱片封面字段，背景继续按现有规则回退。

保存的 URL 是严格受限的同源歌曲入口，例如 `/api/netease/audio/{songId}`，不保存会过期的实际 CDN 地址。校验器只允许符合规则的网易云音频入口，且来源编号必须与 URL 一致。

播放入口通过服务端登录会话请求歌曲实际地址；地址只做有到期时间的内存缓存。上游只返回试听时，明确标记为试听，不把片段当成完整歌曲静默播放；暖场默认要求完整歌曲。

Go 从认可的网易云音频 CDN 流式转发媒体，支持 HEAD、Range 和必要响应头，不把音频整体读入内存。实际连接强制 HTTPS 并校验证书；遵守重定向次数、主机名与公网地址限制，凭据只发送到网易云接口，不转发给音频 CDN。对本机 TUN 代理的 198.18.0.0/15 fake-IP 映射，仅在限定 CDN 的 HTTPS 连接中例外兼容；不接受其他内网地址或明文重定向。流式传输使用可取消请求及独立超时策略，不能因接口短超时截断长歌曲。

公开播放仅允许当前投影可见的已保存歌曲或现有预加载计划中的歌曲；主持人登录后允许素材检查与草稿试听。该入口不能变成任意歌曲的匿名取流服务。答案隐藏规则继续生效。

同源稳定入口继续交给现有 `SyncedMedia` 播放，因此主持端静音预览、投影启用声音、片段起止、暂停、跳转、倍速和“开始茶话会”都复用当前状态机。切页会停止旧媒体。首版不增加自动连播、随机播放或歌词功能。

## 账号会话

凭据仅保存在数据目录的独立私有文件，如 `data/netease/account.json`，目录权限 0700、文件权限 0600，采用原子替换。该目录不位于 `data/media`，不经过静态文件路由。

活动状态、公开 SSE、配置导出、活动 ZIP、浏览器 localStorage 和页面错误信息均不包含网易云 Cookie。浏览器只获取后台所需的登录状态和账号摘要。

二维码任务绑定当前主持后台会话并有有效期。创建新任务、退出账号或后台登出后，旧二维码结果不能覆盖新的状态。重启读取本机凭据，实际请求发现失效后提示重新扫码。退出网易云清除本机凭据、未完成登录任务及取流缓存，之后的新请求不再使用旧账号。

扫码和手机确认由用户操作；测试不要求用户提供密码或粘贴 Cookie。

## Go 对前端的接口

所有账号、导入与账号歌单接口均复用后台认证与现有同源修改检查：

| 接口 | 用途 |
| --- | --- |
| `GET /api/admin/netease/status` | 适配组件与账号状态，不返回凭据 |
| `POST /api/admin/netease/login` | 创建二维码登录任务 |
| `GET /api/admin/netease/login/{task}` | 查询该后台会话的登录进度 |
| `DELETE /api/admin/netease/login/{task}` | 取消二维码任务 |
| `DELETE /api/admin/netease/account` | 退出网易云并清除本机凭据 |
| `GET /api/admin/netease/playlists` | 分页读取当前账号歌单 |
| `POST /api/admin/netease/import` | 解析分享链接、分页读取元数据，不修改活动 |
| `GET /api/admin/netease/tracks/{songId}/availability` | 检查完整歌曲是否可播放，返回可解释的结果 |
| `GET/HEAD /api/netease/audio/{songId}` | 校验可见性并流式提供音频 |

上游适配只允许这些流程所需的方法：二维码、登录状态、用户歌单、歌单详情／全部歌曲、歌曲详情、歌曲播放地址。每次请求明确关闭额外音源匹配，使用当前账号可访问的网易云资源。

## 预检、预加载与备份

- 素材检查能区分完整可播放、需要登录、权限不足、仅试听、歌曲不可用、网络错误；不把同源动态音频误报为缺失本地文件。
- 预加载继续遵守现有单个音视频最多读取开头 1 MB 的限制，不能为了导入或预加载下载整首歌曲。
- ZIP 将网易云媒体标记为在线引用，保存稳定歌曲编号、名称、封面及现有片段设置；不下载歌曲，也不包含账号凭据或临时播放地址。
- 在另一台电脑恢复后，上传素材照常可用；在线歌曲需要联网，涉及账号权限的歌曲需在新电脑扫码。备份预检应明确列出这些在线引用。
- 原有活动文件不做批量迁移，也不重置现有现场进度。演练使用独立测试数据，实施前额外留存当前活动快照。

## 错误与重试

网络超时、接口风控、二维码过期、需要登录、账号权限不足、只有试听以及适配组件缺失均显示对应中文提示。导入失败保留已编辑草稿，不能清空现有媒体。播放失败不自动更换到另一首歌。

临时网络故障保留本机登录信息；只有确认会话失效才要求重新扫码。前端异步结果绑定当前页面和任务，离开页面、切换题目、取消导入后，迟到结果不得写入别的题目。

## 验收与证据

1. 使用可控上游替身验证扫码各状态、任务取消／过期、过期结果隔离、登录持久化、退出和账号凭据不外泄。
2. 验证歌曲链接、歌单分页、分享文字、重复歌曲、容量限制、异常链接、上游失败和草稿隔离。
3. 验证完整曲／试听／无权限的区分，音频 HEAD／Range、地址过期刷新、并发取流、取消、CDN 限制，以及未公开歌曲不可匿名读取。
4. 验证旧活动正常打开、其他页面仍限 30 个媒体、暖场上限 500，ZIP 导出和恢复正确保留在线引用且不含凭据。
5. 运行项目 `make test` 及完整构建；对新增的协议与前端状态逻辑补充行为测试。
6. 在获准的浏览器中用独立测试活动验证导入、未保存预览、主持端与投影的播放／暂停／跳转、切页停止和主题适配。当前会话曾拒绝 Edge 控制，不能将浏览器验收视为已获授权或已完成。
7. 用真实公开曲进行联网试播。会员歌曲需要用户扫码后在本机验收；没有这项证据时，应明确记录尚未完成真实会员账号试播，不能以模拟测试代替。
