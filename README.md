# ef-TeaParty · 冬日茶话会

重庆大学动漫社偶研部的现场答题系统：Go 后端、React 主持后台和独立投影页。活动按页面顺序连续进行，可自定义背景；分数、计时、答案、媒体播放和抽签结果实时同步。

仓库只包含系统代码、内置标识和默认设计、测试与文档。活动题库、答案、积分、抽签记录、上传文件、PPT 原始素材及参考资料均保留在本地，不随代码提交。

已加入用户提供的重庆大学偶研 logo，显示在后台页眉、登录页和投影欢迎页。欢迎页参照 VIS 手册第 4、28–29 页采用竖式组合：上方校徽与偶研标识并列，下方显示单位中英文名称，保持原比例和留白。组合背景透明，偶研图仅去除外部白底，图案内部白色保留；原图与透明版本均位于 `web/src/assets/`。英文暂用 `Idol Research Department, Animation Club / Chongqing University`。透明素材制作记录见 [标识说明](docs/branding.md)。

后台参考 [bandori.fans](https://bandori.fans/zh-Hans) 的米白纸面、黑色字、细线分隔与横向导航；支持浅色／深色切换并在本机记住偏好。下拉菜单与复选框使用统一包装，支持键盘操作、焦点提示和整行点击。

支持暖场、单选题、海龟汤、听歌识曲、你画我猜、开场规则及颁奖页。后台可编辑题目和选项、上下排序、启用/禁用页面，上传图片/音频/视频，设置播放片段及每题团队/个人加扣分。计分可判对、判错、手动调整、撤销及导出 CSV；同题同组重复判分会替换原记录。抽签支持昵称池去重、整数范围、一次多人和不重复抽取。

题库管理上方整行显示所选页面的投影预览，下方为页面列表与编辑表单两列。草稿修改实时反映到预览，可放大、揭晓答案和试听媒体；这些预览操作不会切换现场页面或改变现场播放状态。

现场准备支持投影状态反馈、素材预检与下一页预加载、大文件上传进度与重试、欢迎页显示开关、立绘排版工具，以及包含本地素材的活动 ZIP 备份。操作入口和使用边界见 [现场准备与恢复说明](docs/live-readiness.md)。

## 启动

需要 Go 1.24+、Node.js 22.18+。在项目根目录执行：

```sh
make install
make build
make run
```

打开后台 <http://127.0.0.1:8080/>，密码会显示在启动终端。投影页为 <http://127.0.0.1:8080/stage>，视频在普通窗口中也会自动跟随主持端静音播放；点击「启用投影声音」开启声音，「全屏显示」独立控制显示方式。后台的全屏预览仍属于主持端；现场请把独立投影页移到第二块屏幕。

固定后台密码可以使用环境变量：

```sh
TEAPARTY_ADMIN_PASSWORD='替换为自己的密码' make run
```

第一次启动若本机存在 `assets/seed.json`，使用该本地题库；否则初始化暖场、欢迎、Logo 动画及颁奖四个空白流程页和 A/B/C 三组，不包含活动题目、媒体或历史记录。之后读取 `data/state.json`，不会覆盖后台修改。可在后台导入题库 JSON、上传素材，或通过 `-seed /路径/题库.json` 指定首次启动题库；显式指定的题库缺失或损坏会报错。

无需外部数据库；前端构建完成后，本地题库和上传媒体无需互联网即可使用。远程媒体链接仍需网络。`data/`、`assets/`、`tmp/` 和 `参考资料/` 已加入 Git 忽略规则。迁移实际活动请使用下文的活动 ZIP 备份，与系统代码分开保存。

## 活动前准备

新安装从空白流程开始。在后台建立或导入自己的活动题库，并配置背景、素材和组别。已有本地活动继续读取原存档；系统代码更新不替换活动数据。

1. 在题库管理中核对待确认题目，填写正确答案、解析、媒体后启用。
2. 为猜歌和画猜上传活动音频；可设开始、结束秒数，结束为 0 时播放至结尾。单选题同样支持音视频。建议使用 MP3/WAV、H.264 + AAC 的 MP4 或浏览器支持的 WebM。单个视频最大 3 GB（3 × 1024³ 字节），图片和音频最大 256 MB；视频直接流式写入素材文件。上传面板显示进度、速度和预计剩余时间，可取消；失败后可「重新上传」，重试从头开始。上传完成后仍需保存页面。
3. 保存组别和计分规则。个人分数与团队分数独立计算；填写昵称才记个人分。海龟汤默认团队 +7、个人 +1，后续轮次可手动调整；画猜参与者可以用「团队 0、个人 +1」逐个记分。
4. 保存抽签昵称或数字范围。修改抽签设置会重建池并清空抽签历史。
5. 在题库管理的「入场暖场」上传多个音频或视频、填写片段名称和起止秒数，用上下箭头调整顺序，然后保存。
   暖场纯音频显示旋转 CD 和曲名；播放时转动，暂停、缓冲或结束时停住。「默认 CD 与背景」提供内置的银蓝唱片和冬夜背景，也可上传图片替换默认设计。每首音频展开「本曲 CD 与背景」可分别上传封面、背景或应用图片链接，留空的项目按「本曲 → 本页默认 → 内置设计」逐项回退；「恢复默认」只清除本曲对应设置。点击「预览本曲」在上方查看编辑效果，保存后现场控制与投影生效；自定义图片纳入素材预检和完整活动备份。
6. 在「活动设置 → 活动素材检查」检查背景、立绘、图片和音视频，包含答案素材；默认只检查已启用页面，可勾选包含未启用页面。异常和待确认项可单独筛选，修改题库后应重新检查。检查在主持浏览器中进行，不能代替投影电脑上的实际试播。
7. 打开投影、启用声音，演练切页和媒体播放。主持预览默认静音，避免和投影重复出声。现场控制先切到「暖场」，预览下方的播放清单分为「音频」「视频」两个区域，素材以卡片平铺；点击卡片即在同一页面切换并从设置的起点播放，点击正在播放的卡片可暂停。「开始茶话会」会停止媒体并进入欢迎页。暖场不计分。

视频控制区提供带当前时间／总时长的进度条，拖动松开后同步到投影，支持前进／后退 10 秒和 0.5×、0.75×、1×、1.25×、1.5×、1.75×、2× 倍速。设置片段时，跳转限制在片段与实际文件时长内。暂停、继续和重播保留倍速，切换素材或页面恢复 1×。更新后需同时刷新后台与投影页面。
8. 准备完成后，在「活动设置 → 活动备份与恢复」下载完整活动备份 ZIP，保存到备用电脑或存储设备。

现场控制的「投影端状态」约每 2 秒更新，显示各投影窗口最后回报时间、当前页面和版本、浏览器全屏、声音启用情况、媒体缓冲/播放/错误、实际进度和同步偏差。延迟、离线或尚未同步的窗口会明确标记；后台预览不会计作投影。声音显示「已启用 · 待播放确认」时，仍需播放素材确认。

独立投影会尝试准备下一个已启用页面的可见素材，仅接收 URL 和类型，不提前接收题目正文或答案素材。最多准备四张图片和一个音视频候选：同源图片不超过 4 MB 才完整读取，音视频最多读取开头 1 MB；换页或关闭投影会取消旧任务。远程链接及超限素材在实际显示时正常加载，预加载不代表已完整缓存或保证可播放。

现场控制的「投影视频全屏」让投影端只显示视频，隐藏页面背景、标题和积分；「恢复活动页面」恢复原布局。开关实时同步且不改变播放进度，切换视频保持全屏，翻页或切到音频自动恢复。投影窗口若要隐藏浏览器工具栏，请先在投影端点击一次「全屏显示」，之后后台可以持续切换视频布局。

现场控制的「答题倒计时」支持 15、30、45、60、90、120、180、300 秒预设，以及 1–86400 秒自定义时长，可开始、暂停、继续和重置，投影右下角同步显示。猜歌音频可「直接播放」或「3 秒后播放」；后者在主持预览和投影端显示 3、2、1，随后按同一开始时间播放。取消待播放、翻页或切换素材会取消原等待；答题倒计时独立控制。时间归零时显示“时间到”并播放提示音；投影需要先点击“启用投影声音”。

欢迎页之后是四幕 Logo 集结动画，使用 `web/src/assets/logo` 中的四个原始标识。每个标识以画面宽度约 33% 的尺寸配合斜向光带和大字登场，约 9 秒后四个标识以各 20% 的尺寸汇聚定格。主持端可“重播开场动画”或直接翻页；题库管理可修改标题、正文，在“页面呈现”中切换普通说明页 / Logo 动画，预览重播仅影响草稿。动画按服务器开始时间同步，中途打开投影会跟上进度。后台预览和投影共用经过往返校准的服务器时钟，旧 HTTP 响应不会覆盖较新的同步状态。

题库管理选中欢迎页后，可独立设置「显示团队比分」和「显示倒计时」；关闭后隐藏对应区域，不改变其他页面。比分同时遵循活动全局开关，倒计时开关只控制显示。欢迎页活动标题会随中英文长度调整字号；保存修改后请在预览中检查排版。

开场 / 规则页可在题库管理的“开场立绘”中上传多张图片（每页最多 12 张，推荐透明底 PNG / WebP）。上方预览可拖动位置、拖右下角缩放，方向键微调、Shift 加速；也可输入水平中心、底边位置和宽度百分比，设置左右翻转、画面前后层及同层排列顺序。布局按 16:9 画面比例保存，欢迎页和 Logo 页均支持；草稿操作仅影响编辑预览，保存页面后后台现场预览和投影同步生效。

立绘编辑可显示辅助线和 5% 安全区、启用自动吸附，按住 Alt / Option 临时暂停吸附。排版完成可锁定位置、大小、翻转和层次；本页立绘支持撤销/重做，一次拖动对应一步历史。欢迎页的「恢复推荐排版」恢复现有七位角色的推荐位置、大小、层次和翻转状态，保留上传图片、额外立绘与锁定项。

欢迎页可配置多个企划的透明立绘，每个人物均可独立调整位置和大小。现有本地活动的角色素材来源记录见 [开场角色素材来源](docs/opening-characters.md)；具体立绘文件和配置不随系统代码发布，新安装需自行上传。

应用确认、导入、删除和重置操作使用统一主题弹窗，支持取消、Esc、焦点约束和关闭后恢复焦点。题库未保存修改会保留为本机草稿，刷新或重新进入编辑器后可恢复，不使用浏览器原生离页确认；本机草稿不会自动发布到投影，仍需保存页面。

随机抽签先点击“显示抽签开场页”，再点击“开始抽签”。昵称或数字以连续签条滚动 5–10 秒（每轮随机），起步约每秒 65 格，按共享时间持续减速，最后居中的签条就是本轮真实中奖项；停稳后原位高亮并短暂播放金色纸片效果，不另换结果画面。滚动期间不能重复抽取，返回答题页面保留比分和暂停的计时。

方向键左右翻页，空格下一页，Shift + 空格上一页，R 显隐答案；编辑输入框时不会触发快捷键。切页会隐藏答案并停止旧媒体；积分保留。视频命令预留 300 毫秒共同起播时间，当前素材提前缓冲；拖动后先等待寻址与缓冲恢复；仅对持续明显偏差进行限频校正，避免重复定位打断解码，倍速保持主持人设置。暂停以服务器进度为准。升级后后台和投影都需要刷新一次以加载新的前端。重启保留题库、积分和抽签历史，计时和音视频等待主持人重新启动。旧活动首次升级会在欢迎页前补充暖场页，保留当前页面和已有编辑；旧存档也会在欢迎页后补充 Logo 动画页。之后主动删除默认暖场或动画页不会再次补回。

## 局域网投影与备份

```sh
TEAPARTY_ADMIN_PASSWORD='替换为自己的密码' make lan
```

投影电脑打开 `http://主持电脑局域网IP:8080/stage`，主持后台仍在 `/`。现场网络允许设备互访即可。服务默认仅监听本机；局域网模式监听 `0.0.0.0:8080`。如部署到公网，应在 HTTPS 反向代理后运行。

在「活动设置 → 活动备份与恢复」下载 ZIP，可保存题库、答案、积分、抽签记录、现场进度和活动引用的本地素材，包括答案媒体、立绘和背景；未引用的上传文件不打包。外链只列入清单，恢复后仍需联网；缺失或不可读取的本地素材也会在恢复预检中提示。归档最大 32 GB，单个素材最大 3 GB。另一台电脑先部署应用，再选择 ZIP 预检，核对活动摘要和素材清单后确认恢复。预检后活动发生变化或超过 15 分钟，需重新预检。

恢复会替换当前活动，媒体与倒计时保持暂停。每次恢复前自动保存状态快照到默认数据目录的 `data/pre-restore-*.json`，旧素材和历次恢复目录保留，便于回退，不会自动清理。恢复前另下载一份当前活动 ZIP，可直接通过相同入口回退；自动 JSON 快照不是完整 ZIP，需要原素材配合。仅复制 `data/` 不一定包含引用的 `assets/` 素材。题库 JSON 仅用于导入配置，CSV 用于成绩归档，二者均不包含媒体文件。详见 [备份与恢复步骤](docs/live-readiness.md#备份与恢复)。

## 开发与验证

```sh
make test
# 可选：前端热更新；另一个终端运行 make run
cd web
npm run dev
```

Vite 开发地址为 `http://127.0.0.1:5173`，API 和素材请求代理到 8080。`make test` 执行 Go race 行为测试、前端预览隔离测试和 TypeScript 检查。浏览器验证使用可见 Microsoft Edge 和苹果辅助功能，未使用无头浏览器。暖场和主题改版的验证记录见 [界面验收记录](docs/ui-qa.md)。已验证切页与答案同步、倒计时、判分替换、独立个人加分及撤销、题目修改与排序、多窗口编辑冲突、真实音视频上传/片段播放、答案视频、昵称去重和数字抽签。

指定自己的首次启动题库：

```sh
./bin/teaparty -seed /路径/题库.json -data data
```

本地活动的 PPT 提取工具、原始题库与导入报告不纳入系统仓库。题库 JSON 可以通过后台导入，但不包含实际媒体文件；需要迁移完整活动时使用 ZIP 备份。

目录：`cmd/teaparty` 服务入口与空白初始化、`internal/party` 状态/计分/抽签、`internal/server` HTTP/SSE/登录、`web/src` React 和内置标识、`web/public/assets/warmup` 默认 CD 与背景、`web/tests` 前端行为测试。运行数据位于本地 `data/`，可选 PPT 素材位于本地 `assets/ppt/`。
